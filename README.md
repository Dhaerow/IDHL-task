Following the task requirements I have followed the mock up on figma and recreated the design and functionality. 
I used GULP in my project to minify and compile scss to css and JS. 

For add to cart functionality instead of pre-populating the cart I made it dynamically working with add to cart button. 
Add to cart button also triggers the loading animation of the cart. Cart can also be accessed by clicking the icon (without the loading animation - I assume not required)

To see in the browser please open the index.html under dist directory.
